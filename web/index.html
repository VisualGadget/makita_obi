makita_obi battery tool

Read Makita LXT 18 V batteries through a Wemos D1 mini running the makita_obi firmware. Everything runs in this browser tab, and nothing about your battery is uploaded.

This browser has no Web Serial support, so it cannot reach the adapter. Try a recent Chrome, Edge or Firefox over HTTPS.

First time? Install the firmware

Build the adapter from the wiring guide, then install the makita_obi firmware on its Wemos D1 mini. Take the battery off the adapter first.

This browser can not install firmware. Installing firmware needs an HTTPS page.

Disconnect below first: the installer needs the serial port.

Installer not working? Flash firmware.bin at address 0 with the esptool-js page.

Connection

Loading the tool, about 15 MB on the first visit.

Battery

Reading enters test mode briefly on packs that can not be identified without it. The monitor refreshes voltages and temperatures every 5 seconds, for watching a pack under charge or load.

Unlock

This pack reads as locked. A lockout is often real protection, so unlock only a pack you trust.

This check enters test mode briefly on some packs, and changes nothing.

    Unlocking sends the DA 04 reset. On a real BL1850 that also reset the cycle count and damage rating to 0, and those can not be put back from this page. If the pack stays locked, a repaired frame is written. A failed write can disable the pack.

    Download the backup first. The button stays off until you have.
